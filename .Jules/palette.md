## 2025-05-14 - [Improving Accuracy and Accessibility in Key Code Explorer]
**Learning:** For developer-focused utilities, using technical property names (e.g., `event.key`, `event.code`) as UI labels provides better clarity and context than generic terms like "Key" or "Code".
**Learning:** Implementing `aria-live="polite"` on dynamic content containers is essential for ensuring that real-time updates are announced to screen reader users.
**Learning:** Replacing static, empty initial states with clear instructional messages (e.g., "Press any key...") significantly reduces user confusion upon first interaction.

**Action:** Always prefer technical accuracy in developer tools and prioritize an "instructions-first" UI pattern for interactive utilities.
